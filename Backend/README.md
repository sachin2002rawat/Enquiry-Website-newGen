# Enquiry Website - Backend API

Node.js Express MongoDB REST API backend for Enquiry Website MERN Application.

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Environment Variables
Copy `.env.example` to `.env` and fill in your MongoDB connection URI and configuration values:
```bash
cp .env.example .env
```

### 3. Run Development Server
```bash
npm run dev
```

### 4. Seed Database (Optional)
```bash
npm run seed
```
